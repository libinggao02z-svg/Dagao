# 农夫山泉 · 一瓶水的来处

React + TypeScript + Vite + GSAP ScrollTrigger 的沉浸式滚动叙事源码。已整合本次提供的两段视频、生产纵向长卷、08A 无字落版，以及此前的分镜图片；不用替换占位图也可以直接体验完整旅程。

## 启动

使用 Node.js 22.12+（建议 Node 22 LTS）及 npm。在本目录运行：

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:4174/ 。视频定位需要 HTTP 服务，请勿双击 index.html。

```bash
npm run build      # TypeScript 检查 + 生产构建，输出 dist/
npm run preview    # 本地预览生产构建
npm test           # 时间轴边界、倒滚和转场逻辑测试
```

开发服务和构建预览共用 4174 端口，使用前停止另一个服务。浏览器回归测试见 [验证说明](docs/VALIDATION.md)。部署时把 `dist/` 交给任意静态托管服务；当前使用相对资源路径，支持子目录部署。

## 四部分实现

1. **叙事结构**：八个信息章节、六段媒体场景。瓶身近景 → 穿入瓶中 → 湖面横向展开 → 贴水推进与下潜 → 生产纵向长卷 → 日常与产品落版。参考 [Pear](https://pear.no/) 的单一主体与镜头推进方式，视觉素材和中文叙事独立组织。
2. **滚动框架**：全屏固定舞台 + 一个 GSAP 时间轴，归一化进度 `0–1` 同时驱动镜头、文字、视频和导航。停止滚动即停帧，倒滚反向定位；提供暂停、章节跳转、结尾重播和品牌标识返回开场。默认桌面 22 屏、手机 18 屏的滚动距离。
3. **媒体与转场**：图片、循环视频、滚动视频、Canvas 图片序列，以及横/纵长卷均通过配置切换。支持溶解、圆形遮罩、擦除；同一长卷内部移动同一个图层，保留空间连续性。
4. **信息层与适配**：文字和按钮独立于媒体。手机上方留出阅读区、下方保持产品主体；靠近场景才挂载媒体。系统减少动态效果、节省流量或手动“简洁浏览”进入静态图文版；视频出错回退海报。

## 直接体验不同模式

| 地址参数               | 用途                                       |
| ---------------------- | ------------------------------------------ |
| `/`                    | 已接入提供素材的完整版本                   |
| `/?assets=placeholder` | 仅几何占位，验证完整滚动与章节交互         |
| `/?media=sequence`     | 开场换为 93 帧、10 fps 的图片序列          |
| `/?media=loop`         | 湖面横卷替换为静音循环视频，验证循环适配器 |
| `/?motion=off`         | 静态图文降级版本                           |
| `/#underwater`         | 直接进入指定章节；其他章节 ID 见配置       |

这些是开发验收入口，不出现在访客页面里。占位参数优先于媒体模式参数。

## 当前素材的边界

这是可运行的品牌叙事演示。日常段落目前为四张分镜的连续溶解；开场额外提供真实视频抽帧的 93 帧序列。生产段落是用户提供的纵向合成图，按单一空间移动，并非实际生产工艺的实拍纪录。原素材中的生成水印和图像文字未改动；发布用素材可按配置替换。

滚动视频的画面由浏览器解码定位，精度受编码和设备影响，不等同逐帧剪辑播放器；需要确定帧序时可选择图片序列模式。循环视频按时间自主播放，暂停按钮会暂停它，倒滚只改变所在场景，不倒放循环视频。
